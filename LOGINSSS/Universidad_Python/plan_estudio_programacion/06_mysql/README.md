# Modulo 6 - MySQL

## Antes de comenzar

Aprende SQL basico y practica primero con datos de prueba. No guardes contrasenas reales en tus archivos; usa variables de entorno o un archivo local ignorado por Git.

## Debes dominar

Tablas, claves, `SELECT`, `INSERT`, `UPDATE`, `DELETE`, consultas parametrizadas, transacciones y cierre de conexiones.
