# Plan de estudio de programacion con Python

Esta carpeta acompana el curso y contiene ejercicios para resolver sin copiar soluciones.

## Como usarla

1. Estudia el modulo correspondiente en tu curso.
2. Lee su `README.md` y resuelve los ejercicios del archivo `.py`.
3. Marca cada ejercicio como terminado solo cuando puedas explicar tu solucion.
4. Guarda tus dudas en `apuntes_dudas.md`.
5. Cuando termines un modulo, usa `PROMPT_REVISION_ESTUDIO.md` para pedirme una revision de la carpeta.

## Orden recomendado

- `01_funciones`: antes de pasar a clases.
- `02_clases_objetos`: sintaxis de clases e instancias.
- `03_POO`: encapsulamiento, herencia, polimorfismo y composicion.
- `04_avanzado_python`: excepciones, comprensiones, modulos, lambda y buenas practicas.
- `05_archivos`: TXT, CSV y JSON.
- `06_mysql`: SQL, conexion, CRUD y seguridad basica.
- `07_tkinter`: interfaces y separacion entre interfaz y logica.

No avances por calendario: avanza cuando puedas resolver los ejercicios faciles sin consultar y los intermedios con poca ayuda.
