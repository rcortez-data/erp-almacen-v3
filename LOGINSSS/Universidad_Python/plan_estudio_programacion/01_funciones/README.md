# Modulo 1 - Funciones

## Debes dominar

Definir funciones, parametros, argumentos, `return`, valores por defecto, alcance basico y dividir un problema en funciones pequenas.

## Orden

Resuelve F01 y F02 antes de F03. F04 practica menus. F05 es el proyecto de cierre.

## Criterio para avanzar

Puedes crear funciones que reciban datos, devuelvan resultados y validen entradas sin depender de variables globales.
