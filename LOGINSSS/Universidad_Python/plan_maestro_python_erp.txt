12. REGLA SOBRE GITHUB COPILOT
============================================================

Puedes usar GitHub Copilot, pero con control.

No lo uses para que piense por ti.
Usalo como apoyo, no como piloto automatico.

Regla recomendada:

1. Primero intenta escribir tu idea en comentarios o pseudocodigo.
2. Escribe al menos la estructura principal tu.
3. Si Copilot sugiere codigo, leelo antes de aceptarlo.
4. Acepta solo lo que entiendas.
5. Modifica el codigo con tus propias decisiones.
6. Si no puedes explicar una linea, no la dejes sin preguntarla.

Buena forma de usarlo:

# pedir edad
# validar si es mayor de edad
# imprimir resultado

Luego dejas que sugiera, pero tu revisas.

Mala forma de usarlo:

Aceptar todo sin entenderlo.

Para aprender mejor:
- En ejercicios nuevos, intenta primero sin Copilot.
- En ejercicios largos o repetitivos, puedes usarlo.
- En retos importantes, puedes hacer una primera version tu solo y luego comparar con Copilot.

Conclusion:
No hace falta quitar Copilot.
Pero debes usarlo como maestro auxiliar, no como sustituto de tu logica.
